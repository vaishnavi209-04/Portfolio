## Installation

Clone the repository:

```bash
git clone https://github.com/vaishnavi209-04/Portfolio.git
```

Navigate to the project folder:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
